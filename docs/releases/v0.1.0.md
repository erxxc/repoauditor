# RepoAuditor 0.1.0

RepoAuditor 0.1.0 is the first citable public software release of the completed proof of
concept. The optimization lifecycle records 38 closed bounded scopes and zero open items.

## Included

- deterministic scanner execution, provenance, canaries, and failure accounting;
- package-local Java and Python weak-RNG syntactic candidate detectors;
- bounded architecture, retrieval, slicing, finding review, and reporting workflows;
- temporal and family-aware descriptive evaluation evidence;
- leadership and engineering reports with explicit quantitative claim boundaries; and
- reproducible Python dependencies in `uv.lock`.

## Evidence and safety boundaries

Findings are review candidates. This release does not claim exhaustive vulnerability recall,
automatic actionability, exploitability, compromise, predictive validity, optimal thresholds,
or production readiness. The weak-RNG detectors do not execute state recovery or import the
independent PRNG Lattice Lab.

Live model-backed workflows require separately supplied credentials and can incur provider
costs. No credentials, production audit database, acquired repository snapshots, or local
execution artifacts are included in the source release.
